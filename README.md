## 🚀 About Me

I'm a passionate **Full-Stack Developer** and a **Solo Founder** based in Cambodia 🇰🇭. My mission is to break down the language barrier in tech and make programming education accessible to everyone in the **Khmer language**.

- 🏗️ **Founder** of [CodeKhmerLearning](https://codekhmerlearning.site) — An interactive platform for learning to code in Khmer. *(Featured by Technology Cambodia)*
- 🎬 **Founder** of [CodeKhmerVideo](https://codekhmervideo.site) — A video tutorial platform for Khmer developers, powered by **PostgreSQL**.
- 🔭 I'm currently building and scaling both platforms as a solo developer, handling everything from UI/UX design to backend architecture and DevOps.
- 🌱 I'm deepening my expertise in **FastAPI**, **PostgreSQL**, and building robust microservices.
- 👯 I'm open to collaborating on **EdTech** projects and **Open Source Khmer Dev Tools**.
- 💬 Ask me about full-stack development, the Khmer dev ecosystem, or the journey of building platforms from scratch.
- ⚡ Fun fact: I believe that code is a universal language, but learning it in your mother tongue makes all the difference.
